## 2026-04-27 - Semantic Buttons for Interactive SVGs\n**Learning:** When converting div-based or svg-based icons to semantic buttons in an existing application, applying a thorough CSS reset (background: transparent, border: none, color: inherit, padding: 0) and ensuring children SVGs have 100% width and height is crucial to maintain perfect visual parity while drastically improving keyboard and screen-reader accessibility.\n**Action:** Standardize the use of semantic buttons with aria-labels over divs and standalone SVGs for all interactive icons and apply standard CSS resets for integration.
