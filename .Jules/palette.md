## 2025-05-18 - Semantic Icon Buttons vs Event Delegation
**Learning:** In a highly interactive app that relies on event delegation matching specific HTML tags or structural paths (e.g. `.header-icon:last-child` for menu click handling), converting visual `div` and `svg` interactive elements into proper, accessible semantic `<button>` wrappers must be done carefully. Replacing an inline SVG with a button containing an SVG can accidentally break click target paths if the outer wrapper doesn't retain both the class hook and any relevant `data-action` tags.
**Action:** Always migrate specific `data-action` attributes and exact positioning/structural class names to the new parent `<button>` wrapper. Further, pair this with an aggressive button CSS reset (`background: transparent; border: none; padding: 0; color: inherit; display: inline-flex; align-items: center; justify-content: center;`) and inner `width/height: 100%` on the SVG to fully preserve layout flow while immediately upgrading accessibility and keyboard navigation.
