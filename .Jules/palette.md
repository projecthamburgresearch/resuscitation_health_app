
## 2025-02-14 - Semantic button wrappers for interactive icons
**Learning:** In a heavily SVG-driven interactive application, raw `<svg>` elements or un-semantic `<div>` elements attached with Javascript `onclick` listeners miss native semantic button properties, meaning no proper screen-reader label, no native keyboard focus-ability, and no predictable default behaviour. The design system uses precise visual styling, but adding semantic wrappers using a thorough CSS reset (`background: transparent; border: none; padding: 0; display: inline-flex; align-items: center; justify-content: center; color: inherit;`) and setting `pointer-events: none` on child `<svg>` elements flawlessly retains visual parity while adding robust accessibility benefits.
**Action:** When working on interactive SVG or `<div>`-based buttons, ALWAYS wrap them in `<button>` with a proper `aria-label` and apply reset styling instead of trying to add ARIA roles/attributes to divs or SVGs directly.
