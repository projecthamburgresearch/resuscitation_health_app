## 2026-04-07 - Semantic Icon Conversion\n**Learning:** When converting <div> or <svg> icons to semantic <button> elements for accessibility, applying a CSS reset (background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;) is crucial to maintain existing layout and visual hierarchy, along with setting the internal svg to 100% width and height.\n**Action:** Always include this specific CSS reset and internal SVG sizing when converting non-semantic icons into buttons to prevent visual regressions while improving accessibility.
