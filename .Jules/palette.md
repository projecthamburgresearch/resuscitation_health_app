## 2026-07-01 - Added semantic buttons and ARIA labels for UI icons
**Learning:** Replaced pure SVG/div elements acting as interactive icons with semantic HTML `<button>` tags. Adding a CSS reset (`background: transparent; border: none; padding: 0;`) preserves the original layout, but a crucial detail is to add `pointer-events: none;` to the nested `<svg>` elements. This ensures click events target the `<button>` element directly instead of the child SVG, maintaining compatibility with any event delegation logic (like in `menu.ts`) that relies on `e.target` attributes (e.g., `data-action`).
**Action:** When converting non-semantic UI icons to semantic buttons, always apply the layout-preserving CSS reset and set `pointer-events: none` on nested children to prevent breaking event delegation.
