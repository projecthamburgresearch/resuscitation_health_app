## 2024-03-24 - Converting DIV/SVG Icons to Semantic Buttons
**Learning:** When converting div or SVG icons to semantic `<button>` wrappers in this repository for accessibility, it is crucial to migrate both the structural CSS classes (e.g., `header-icon`, `card-icon`) and functional data attributes (e.g., `data-action`) to the newly created parent `<button>` element. Event delegation (e.g., in `app/src/ui/menu.ts` or `app/src/cards/renderer.ts`) relies heavily on matching these specific classes and dataset properties on the clicked target or its closest ancestor. Furthermore, structural pseudo-selectors like `.header-icon:last-child` are used to bind events, so the wrapping `<button>` must retain these exact class names in the correct DOM order.
**Action:** Always verify that interactive attributes (`data-action`, `onclick`) and primary structural CSS classes are moved to the wrapper `<button>`, while applying comprehensive CSS resets to the button (`background: transparent; border: none; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) and sizing the inner `<svg>` elements to `100%` width and height to preserve the visual layout precisely.
