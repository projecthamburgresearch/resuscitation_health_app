## 2024-05-18 - Semantic Icon Buttons
**Learning:** In the Resuscitation App, interactive icons (like the header menu, overflow dots, and card icons) were implemented using generic `<div>` or `<svg>` tags. When updating to semantic `<button>` elements to improve accessibility (enabling keyboard focus and screen reader labels), we must apply a comprehensive CSS reset (e.g., `background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) and set the child SVG dimensions to 100% to ensure visual parity with the legacy div-based layout. Also, we must preserve any structural classes and sequence, as event delegation relies on them (e.g., `.header-icon:last-child` for menu triggers).
**Action:** Always wrap interactive SVGs in semantic `<button>` elements with `aria-label`s, accompanied by appropriate CSS resets, when updating this codebase.
