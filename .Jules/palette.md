## 2024-05-18 - Semantic Buttons for Interactive Icons\n**Learning:** When converting div/svg-based interactive icons to semantic `<button>` wrappers in this codebase, adding `pointer-events: none;` to the child `<svg>` elements is crucial to ensure that click events correctly target the parent button and trigger its associated event listeners (e.g., `data-action` handlers) or inline handlers (like `onclick="openFullscreen()"`), preventing the SVG from swallowing the event.\n**Action:** Always wrap interactive SVGs in semantic buttons with `aria-label`s, apply button CSS resets to preserve visual layout, and apply `pointer-events: none;` to the child SVGs.
