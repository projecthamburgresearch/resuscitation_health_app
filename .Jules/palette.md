## 2024-05-24 - Semantic Buttons for Icons\n**Learning:** The application uses `<svg>` tags directly for interactive icons (like the fullscreen and toolbox toggles in cards) which lack built-in keyboard accessibility and ARIA roles. Converting them to `<button>` wrappers ensures semantic HTML and screen reader support without breaking layout if a global reset is applied.\n**Action:** Use semantic `<button>` wrappers with `aria-label` for icon-only interactive elements.
