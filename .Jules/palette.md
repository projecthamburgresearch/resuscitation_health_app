## 2026-10-29 - Convert header and overflow menu icons to semantic buttons
**Learning:** Using `div` and `svg` for interactive icons without native accessibility attributes (like `aria-label`) breaks screen reader usability. Event delegation architectures (like `app/src/ui/menu.ts`) require that inner SVGs have `pointer-events: none;` to prevent them from intercepting clicks meant for the semantic parent button.
**Action:** Always wrap interactive SVGs in native `<button>` elements with clear `aria-label`s. Ensure that child elements (`<svg>`, `<path>`) have `pointer-events: none` and match the parent dimensions (`width: 100%; height: 100%;`). Apply standard CSS resets (`background: transparent; border: none; padding: 0; color: inherit;`) to maintain visual design while inheriting keyboard support.
