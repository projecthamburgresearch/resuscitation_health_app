## 2025-06-13 - Semantic Button Wrappers for SVGs
**Learning:** When using SVGs as clickable UI icons (e.g., fullscreen, toolbox), placing an `onclick` handler directly on the SVG fails to provide native keyboard accessibility (tab focus, enter/space interaction) and screen reader support. Wrapping them in semantic `<button>` elements with `aria-label` attributes ensures accessibility.
**Action:** When converting div/svg-based icons to semantic buttons, apply a CSS reset (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) to the button and set `pointer-events: none` on the inner `svg` to ensure click events reliably target the parent button element and maintain the existing visual layout.
