## 2023-10-27 - Converting Actionable SVG/Div to Semantic Buttons
**Learning:** In the Resuscitation Health App, replacing div or SVG wrappers with semantic `<button>` elements requires transferring functional `data-action` or `onclick` attributes to the newly created button, maintaining the `pointer-events: none` on child elements (like `<svg>`) to ensure consistent event delegation behavior (such as `closeModal()`, `openFullscreen()` or `openToolbox()`). Also, extensive CSS resets are necessary (`background: transparent; border: none; padding: 0; color: inherit; display: inline-flex; justify-content: center; align-items: center;`) to preserve the identical visual layout alongside the a11y improvements.
**Action:** When migrating interactive icon components to use semantic `<button>` wrappers across this app in the future, always implement the comprehensive CSS reset block and apply `pointer-events: none; width: 100%; height: 100%;` to the child SVGs to ensure layout and interaction event handling (like delegation inside `menu.ts`) remain unchanged while meeting WCAG standards.
