
## 2024-05-18 - Semantic Wrapper Pattern for SVG Icons
**Learning:** In this application, replacing simple `<div>` or standalone `<svg>` elements with natively focusable `<button>` wrappers for icons (like fullscreen and toolbox) provides a substantial accessibility boost (keyboard navigation & screen reader `aria-label` support). However, since these icons were previously sized directly on the `<svg>` or `<div class="card-icon">`, introducing a `<button>` wrapper alters the DOM depth and can disrupt the tight visual alignment of absolute positioning if not carefully reset.
**Action:** When converting icon-only elements to `<button>` wrappers in this app, always map the original sizing/positioning classes to the `<button>`, apply a strict CSS reset (`background: transparent; border: none; padding: 0; display: inline-flex; justify-content: center; align-items: center;`), and explicitly size the inner `<svg>` to `width: 100%; height: 100%;` to perfectly mimic the old layout while gaining semantics.
