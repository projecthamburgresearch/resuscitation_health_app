## 2026-05-16 - Convert icon divs to semantic buttons
**Learning:** When dealing with legacy UI elements like icon SVGs or divs acting as buttons, directly applying click listeners without semantic tags severely hampers accessibility. Wrapping them in `<button>` tags with an `aria-label` ensures screen reader and keyboard accessibility. A comprehensive CSS reset (background: transparent, border: none, color: inherit, padding: 0) along with setting `display: inline-flex` and forcing child SVGs to `width: 100%; height: 100%` flawlessly preserves visual alignment and existing layout constraints while adopting semantic markup.
**Action:** Always wrap interactive icon elements in semantic `<button>` tags equipped with appropriate ARIA attributes. Implement a standardized CSS reset on the button to prevent unintended default browser styling and to ensure the icon seamlessly integrates visually.
