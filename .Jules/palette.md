## 2024-04-18 - Avoid action-bound divs and svgs for better accessibility
**Learning:** In the Resuscitation Handbook, interactive icons in the header and cards were implemented directly as actionable `<svg>` or `<div>` elements. This bypasses keyboard accessibility and prevents screen readers from understanding their purpose, which is especially critical in high-stress clinical environments.
**Action:** When implementing icon-only controls, always wrap the `<svg>` in a semantic `<button>` element with an appropriate `aria-label`. Apply a CSS reset (`background: transparent; border: none; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) to the button and set the child `<svg>` width and height to `100%` to perfectly preserve the original visual layout and dimensions.
