## 2026-03-27 - Proper CSS resets for semantic icon buttons
**Learning:** When progressively enhancing div/svg based icons into accessible semantic `<button>` elements, it's critical to apply comprehensive CSS resets (`background: transparent; border: none; padding: 0; color: inherit;`) along with flexbox centering (`display: inline-flex; align-items: center; justify-content: center;`) to prevent default browser button styles from visually breaking the layout.
**Action:** Always apply this standard reset pattern when converting non-interactive elements to buttons to preserve visual design while fixing accessibility.
