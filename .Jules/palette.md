## 2026-04-06 - Semantic Buttons for Icons
**Learning:** When converting div/svg-based icons to semantic buttons in this repository, applying a comprehensive CSS reset (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) perfectly preserves the existing layout and visual hierarchy while improving accessibility.
**Action:** Always apply this CSS reset when refactoring non-interactive UI elements into interactive semantic buttons to avoid unintended design changes while adhering to UX accessibility standards.
