## 2024-06-11 - Converting Div/SVG Icons to Semantic Buttons
**Learning:** When improving accessibility by converting `<div>` or `<svg>` icons to semantic `<button>` elements, standard browser button styling can severely break custom UI layouts. Applying a specific CSS reset pattern (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) perfectly neutralizes the native button styling. Furthermore, applying `pointer-events: none; width: 100%; height: 100%;` to the child `<svg>` ensures that click events reliably target the parent button element instead of the inner SVG, which is critical for event delegation to function correctly.
**Action:** When creating icon-only buttons in the future, always use this explicit CSS reset and SVG pointer-events combo to ensure semantic `<button>` elements remain visually identical to raw icons while functioning perfectly with JavaScript event listeners.
