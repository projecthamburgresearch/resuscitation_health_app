
## 2024-05-18 - Semantic Wrapper Refactor Preserving Delegation and Visual Harmony
**Learning:** When migrating standalone functional `<svg>` icons to standard accessible `<button>` components in legacy codebases, relying on DOM structural selectors (e.g., `:last-child`) in delegating parent scripts means that simply wrapping them will break functionality if the original class name and hierarchy aren't precisely mirrored onto the wrapper. Furthermore, preserving pixel-perfect alignment without custom rules requires applying a full CSS reset (`background: transparent; border: none; padding: 0; color: inherit;`) on the wrapper combined with explicit flexbox alignment and inheriting 100% dimensions on the child vector.
**Action:** Always move the class name from the `svg` to the `button` when wrapping, verify what selectors existing scripts (like `app/src/ui/menu.ts`) use, and standardize the application of the CSS reset block for invisible wrappers to avoid regressions.
