## 2025-02-23 - Use CSS resets for semantically correct accessible buttons
**Learning:** When converting div-based icons to semantic buttons in this repository, they might break the visual layout if not restyled.
**Action:** Apply a comprehensive CSS reset (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) to perfectly preserve the existing layout and visual hierarchy while improving accessibility.
