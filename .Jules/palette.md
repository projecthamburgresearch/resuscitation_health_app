## 2026-05-21 - [Converting Interactive SVGs to Buttons]
**Learning:** Raw SVGs acting as interactive icons aren't natively focusable or announced as actionable by screen readers. Wrapping them in semantic `<button>` elements adds full keyboard accessibility and screen reader support without breaking visual fidelity or layout when combined with an appropriate CSS reset (`background: transparent; border: none; padding: 0; display: inline-flex; align-items: center; justify-content: center;`). Additionally, resizing the inner SVGs to `width: 100%; height: 100%;` maintains their original defined scaling while making the button encompass the entire interactive area.
**Action:** When finding raw SVG elements used for click actions, evaluate converting them into button wrappers with proper ARIA labels. Apply CSS resets to `<button>` to normalize their visual impact completely and make the inner `<svg>` scale using inline properties.
