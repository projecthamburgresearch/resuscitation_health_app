## 2024-05-07 - Semantic button conversions require functional data attribute preservation
**Learning:** When converting non-semantic interactive elements (like divs or svgs) to semantic `<button>` wrappers to improve a11y, it's critical to ensure that any functional attributes, classes or data attributes required by event delegation logic (e.g., in `app/src/ui/menu.ts`) are preserved or migrated to the new parent `<button>` element so that existing event listener structural targetting (e.g. `.header-icon:last-child`) and delegation continues to function correctly without regressions.
**Action:** Always check JS files corresponding to UI elements being updated for class-based selection and delegation patterns before modifying the DOM, and preserve those exact selectors/classes on the new wrapper elements.
