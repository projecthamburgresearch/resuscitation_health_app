## 2024-04-11 - Converting App Shell Elements to Accessible Buttons
**Learning:** For application-critical structural elements like header icons and overflow menus that were previously implemented as inaccessible SVGs or bare divs, converting them to semantic `<button>` elements with `aria-label` attributes ensures keyboard navigation and screen reader support without breaking the visual hierarchy when paired with a CSS reset (`background: transparent; border: none; color: inherit; display: inline-flex; justify-content: center; align-items: center;`) and nested `svg` dimension enforcement (`width: 100%; height: 100%;`).
**Action:** When migrating legacy visual controls in this app to semantic, interactive elements, always apply this CSS reset pattern to preserve existing geometry and use specific element selectors (e.g., `button[aria-label="..."]`) instead of unreliable DOM position selectors (e.g., `:last-child`) for event bindings.
