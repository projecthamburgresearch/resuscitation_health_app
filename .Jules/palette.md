## 2025-02-14 - Semantic button upgrades for standalone icons
**Learning:** In a heavily customized custom-UI application with div/svg-based icon controls (like `.header-icon` and `.overflow-btn`), replacing them with semantic `<button>` elements equipped with `aria-label` attributes ensures screen-reader visibility while a pure CSS reset (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) perfectly preserves the complex legacy layout geometry.
**Action:** Always check the `app/src/styles/layout.css` and use semantic tags with resets instead of `div` or standalone `svg` when adding interactive iconography, remembering to update JS selectors (e.g. `button[aria-label="Menu"]`) that may have relied on structural pseudo-classes.
