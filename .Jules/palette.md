## 2024-02-15 - Semantic Button Conversions for Icons
**Learning:** In legacy codebases or prototypes, icon-only interactive elements are frequently implemented as `<div>` or `<svg>` elements with click handlers. This creates critical accessibility gaps for keyboard navigation and screen reader users. When converting these to semantic `<button>` elements, standardizing a CSS reset is crucial to prevent visual regressions while enabling accessibility.
**Action:** When finding `<div>` or `<svg>` elements acting as buttons, always wrap or convert them to semantic `<button>` elements. Ensure to add `aria-label` attributes for icon-only buttons, apply `pointer-events: none` to child SVGs to maintain event delegation, and use a consistent CSS reset (`background: transparent; border: none; padding: 0; display: inline-flex; ...`) to preserve original component styling.
