## 2025-02-20 - Semantic buttons for interactive elements
**Learning:** The application extensively utilizes non-semantic `<svg>` and `<div>` elements with generic click handlers for its interactive controls (e.g. `.header-icon`, `.overflow-btn`, `.card-icon`). While CSS provides visual interaction cues, this pattern is completely opaque to screen readers and keyboard navigation, causing severe accessibility gaps.
**Action:** When working on UI enhancements in this codebase, actively scan for `div` or `svg` tags attached to click event listeners or structured to look like buttons. Consistently refactor them to use semantic `<button>` wrappers with comprehensive CSS resets (e.g., `background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) and explicit `aria-label`s. Ensure that any functional data attributes (like `data-action`) and layout-critical sizing on SVG children (e.g. `width: 100%; height: 100%;`) are properly preserved so that behavioral and visual parity remains intact.
