## 2026-03-30 - Convert div-based icons to semantic buttons
**Learning:** In this application, many interactive header icons and overflow menus were originally built using non-semantic `<div>` or `<svg>` elements. Adding ARIA labels to these is good, but converting them to semantic `<button>` elements with ARIA labels is better for keyboard accessibility and screen reader support. However, to avoid visual regressions, a comprehensive CSS reset must be applied to these new buttons.
**Action:** Always use a CSS reset (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) when converting existing div-based or svg-based icon controls into semantic `<button>` elements to preserve the visual design while enhancing UX/a11y.
