## 2024-05-01 - Add Semantic Buttons and ARIA Labels
**Learning:** Icon-only buttons implemented directly with SVGs (like `.header-icon` and `.card-icon` or `overflow-btn`) without text lack semantic meaning and proper accessibility for screen readers and keyboard navigation. Using `aria-label` or wrapping them in `<button>` elements provides the necessary context and focusability. Wrapping in buttons requires applying standard css resets to maintain layout and structure since some javascript uses structural selectors (e.g. `document.querySelector('.header-icon:last-child')`).
**Action:** When creating icon-only buttons, prioritize using semantic `<button>` elements with `aria-label` attributes over plain SVG or `<div>` elements. Apply CSS reset (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) to buttons to prevent altering existing layout/styling. Ensure child SVGs use `width: 100%; height: 100%;` relative to parent size, maintaining structural layout parity for selectors relying on class structures.
