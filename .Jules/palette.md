## 2025-02-27 - Semantic Button Wrappers for Accessible SVGs
**Learning:** When converting `<div>` or `<svg>` icons to semantic `<button>` wrappers for improved accessibility (enabling keyboard navigation and screen reader support via `aria-label`), any event delegation logic targeting data attributes (e.g., `data-action`) on the icons will break if those attributes remain on the child elements.
**Action:** Always migrate functional attributes (e.g., `data-action`, `onclick`) to the new parent `<button>` element. Ensure a comprehensive CSS reset is applied (`background: transparent; border: none; color: inherit; padding: 0; display: inline-flex; align-items: center; justify-content: center;`) with `svg { width: 100%; height: 100%; }` to perfectly preserve the visual layout while making the component accessible.
