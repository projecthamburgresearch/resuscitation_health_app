## 2024-04-13 - Semantic Button Refactoring in Dual-Mode Architecture
**Learning:** When addressing accessibility issues in this app's components, specifically converting unsemantic `<div>` and `<svg>` icons to `<button>` elements, the change must be synchronized across both the modular `app/src` structure and the monolithic `app/Resuscitation_App_Complete.html` file. Furthermore, the UI logic (e.g., `menu.ts`) may rely on specific DOM structures (`.header-icon:last-child`); updating elements to be more semantic requires migrating query selectors to use ARIA attributes (`button[aria-label="Menu"]`) to prevent breaking existing functionality.
**Action:** When applying micro-UX enhancements, always check for the component's existence in both the modular source and the `Resuscitation_App_Complete.html` monolithic file. Ensure that DOM queries in the TypeScript source are updated to reflect semantic structures rather than fragile structural positioning.
