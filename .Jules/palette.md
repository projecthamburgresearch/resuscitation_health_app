## 2024-05-24 - Semantic Button Icon Wrappers\n**Learning:** Converting `div` and `svg` based clickable elements to semantic `<button>` wrappers improves screen reader accessibility and requires a robust CSS reset (`background: transparent; border: none; padding: 0; display: inline-flex;`) to maintain visual layout parity, along with `pointer-events: none` on child SVGs to ensure accurate click event targeting.\n**Action:** Apply this robust CSS reset pattern whenever converting non-semantic icons into accessible `<button>` components in this codebase.
