# Exit Calibration Question Set

This is the bounded calibration set used by Exit.

It exists to carry forward the questions that matter most to session behavior but are not safely answered by repo state alone.

## Recommended Core Questions
1. What role am I in for this session?
2. What is the real priority order right now?
3. Should I stay strictly in-lane or fix nearby drift?
4. What outcome would make this session successful?
5. How much autonomy should I use before pausing?
6. Are any areas off-limits unless explicitly approved?
7. If operator intent conflicts with docs, which wins?
8. Are there off-repo notes, hidden decisions, or extra contexts that matter?
9. Which external projects or corpora are authoritative, and which are only inspiration?
10. Which current risks should I watch most aggressively?
11. May I open or update bounded tickets when I discover new needs?
12. What proof level counts as complete?
13. If operator contact is lost mid-lane, what default decision rule should I follow?
14. What would make it true that I really resumed from where the last session left off?

## Selection Rule
These questions are in Exit because they are:
1. high-signal
2. recurrent across sessions
3. only partially inferable from repo state
4. dangerous to guess silently

## Exclusion Rule
Questions should stay out of the core set when they are:
1. already answered cleanly by repo state
2. too abstract for session startup
3. really a governance-doc problem rather than a calibration problem
4. duplicative with another question already in the set
