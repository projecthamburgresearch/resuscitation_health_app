# Artifact Reading Guide: Resuscitation Health App

## Current Warden Outputs
This project currently treats these roots as canonical:
1. `appendix/guidance/warden/blueprint_outputs/`
2. `appendix/guidance/warden/scans_outputs/`
3. `appendix/guidance/warden/design/`
4. `appendix/guidance/warden/report/`

## How To Read Them
1. `blueprint_outputs/`
- static structure and dependency evidence

2. `scans_outputs/`
- route and telemetry evidence, including current snapshots and archived runs

3. `design/`
- design bundle output and screenshot/split linkage

4. `report/latest_analysis.md`
- latest human-readable Warden summary

## Headmaster Rule
Headmaster should treat these outputs as the current-state evidence layer and should not rename or relocate them without a dedicated normalization lane.
