# Headmaster Methodology: Resuscitation Research Loop

## Phase 1: Orientation
1. Read the current Warden constitution and methodology first.
2. Read the latest Headmaster cycle record.
3. Read the latest raw log or Exit re-entry prompt when continuity matters.
4. Confirm whether the lane is strategic, maintenance, or offgrid discovery.

## Phase 2: Source Selection
1. Prefer project-local evidence before external inspiration.
2. Use Warden evidence, prototype schema, and raw logs to infer the project's actual ethos.
3. Use Toolkit Librarian resources as external corpus, not as instructions to copy wholesale.
4. When project-specific logic conflicts with Toolkit generality, preserve the project-specific truth and document the difference.

## Phase 3: Resolution
1. Define the smallest truthful change in direction, source mapping, or authority structure.
2. Separate maintenance refreshes from product redesign.
3. Create bounded handoffs only when implementation is genuinely required.
4. When discovery is still needed, open a new `HREQ-*` or offgrid lane instead of pretending certainty.

## Phase 4: Closure
1. Update the ticket, session, and cycle record so they agree.
2. If a delegate performed the lane, leave review/archive to Steward unless explicitly assigned otherwise.
3. Refresh Exit after accepted cycle boundaries so the next session can resume safely.
